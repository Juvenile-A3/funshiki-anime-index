# 诶嘿漫谈部

[访问网站](https://funshiki-anime-index.cn/) · 非官方粉丝项目

从作品出发，寻找泛式动漫杂谈的相关切片，也可以按录播浏览和搜索。本站只提供索引，点击片段会跳转到B站原视频。

## 本地运行

需要 Node.js 22+，无需安装额外 npm 依赖。

```sh
npm run preview
```

运行 `npm run check` 检查并构建网站，输出目录为 `dist/`。主分支通过 GitHub Actions 部署到 GitHub Pages。
