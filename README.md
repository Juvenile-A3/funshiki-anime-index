# 泛式杂谈索引

[访问网站](https://funshiki-anime-index.cn/) · 非官方粉丝项目

从作品出发，找到泛式谈及它的录播片段。片段数据来自「泛式档案」提供的《上传作品信息.csv》；作品原名、别名、封面及类型依据 Bangumi 作品 ID 补充。

当前公开索引包含 216 部作品、35 期录播、645 个片段，录播投稿日期覆盖 2026-03-08 至 2026-10-04。源 CSV 保留在仓库中，网站读取 `data/catalog.json`；原表中的视频制作字段不进入网站。

## 网站功能

- 搜索作品名称、原名、别名和 ID，按类型、季度筛选。
- 按作品或录播查看片段与时间轴，跳转到原视频的对应分 P 和时间点。
- 浏览源链接与来源信息。发现错误可使用仓库的纠错 Issue 模板反馈。

## 本地预览

需要 Node.js 22+。

```sh
npm run dev
npm run check
```

网站由 GitHub Pages 发布。构建只包含静态页面、公开目录和站点配置。

## 数据来源

切片数据由「泛式档案」整理；作品元数据来自 [Bangumi](https://bgm.tv/)；原录播链接指向[下播型泛式录播组](https://space.bilibili.com/281341996/favlist)等公开投稿。本项目只建立索引，不托管录播视频。图片与整理内容保留各自来源权利。
